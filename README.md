# NTP-Sync

macOSでNTPサーバーへの強制時刻同期をワンクリックで実行するアプリケーション。

屋外での4G Wi-Fiルーター経由のアマチュア無線運用(WSJT-X / FT8等)時に、Macの時計ズレによるデコード失敗を防ぐことが目的です。

## 背景

- 屋外の4G回線環境で `time.apple.com` へのNTP同期がタイムアウトすることがある
- `ntp.nict.jp` (NICTの日本標準時サーバー)の方が経路が安定しており推奨
- FT8等のデジタルモードは時刻ズレに極めて敏感(±1秒程度でデコード不能)

## 使い方

### 基本的な使用方法

1. **NTP-Sync.app** をダブルクリック
2. パスワード入力ダイアログが表示される（管理者権限が必要）
3. Macのパスワードを入力して実行
4. 通知センターに同期結果が表示される

### 通知内容

- **成功時**: 「時刻同期完了」と表示
- **エラー時**: エラーの種類に応じて以下が表示される
  - パスワードキャンセル: 「管理者パスワードが必要です。キャンセルされました。」
  - ネットワーク不通: 「NTPサーバーに接続できません。」
  - ホスト名解決失敗: 「NTPサーバーが見つかりません。」
  - 権限エラー: 「管理者権限の実行に失敗しました。」

### Dockやデスクトップに配置

Finderで `NTP-Sync.app` をドラッグ&ドロップして、常にアクセス可能な場所に配置できます。

```bash
# Dockに追加する例
cp -r NTP-Sync.app ~/Applications/
```

## テスト方法

### 1. 正常系テスト（ネットワーク接続時）

```bash
# アプリを実行
open NTP-Sync.app

# または、コマンドラインから直接実行
osascript NTP-Sync.applescript
```

実行するとパスワード入力ダイアログが表示されます。

### 2. エラー系テスト

#### ネットワーク不通時
```bash
# ネットワークをオフにしてアプリを実行
open NTP-Sync.app
# 「NTPサーバーに接続できません。」が表示される
```

#### パスワードキャンセル時
```bash
open NTP-Sync.app
# パスワード入力ダイアログで「キャンセル」をクリック
# 「管理者パスワードが必要です。キャンセルされました。」が表示される
```

### 3. 時刻オフセット確認

実行前後の時刻ズレを確認：

```bash
# 同期前の時刻確認
date

# アプリを実行
open NTP-Sync.app

# 同期後の時刻確認
date

# または、直接NTPで同期を確認
sntp ntp.nict.jp
```

## 実装詳細

### 使用技術
- **言語**: AppleScript
- **コンパイル**: `osacompile` により .app 形式に変換
- **実行方式**: GUI パスワードダイアログで管理者権限取得
- **通知**: 通知センター

### 実行コマンド
アプリは内部的に以下のコマンドを実行しています：

```bash
sntp -sS ntp.nict.jp
```

- `sntp`: Network Time Protocol クライアント
- `-s`: システムクロックを設定
- `-S`: syslog へ通知（オプション）
- `ntp.nict.jp`: NICTの日本標準時サーバー

### エラーハンドリング
以下のエラーケースに対応：
- パスワードダイアログのキャンセル (error -128)
- ネットワークタイムアウト
- ホスト名解決失敗
- 権限不足
- その他の実行エラー
